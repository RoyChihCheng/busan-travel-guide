## 🌟 核心特色與實地導航亮點

- **5 大維度實景路標無死角認路系統**：
  1. 🚇 **地鐵線路與車站官方色彩速查**：涵蓋 🔴 1號線（橘紅）、🟢 2號線（綠色）、🔵 東海線（深藍）、🟣 輕軌（紫色）官方配色代碼與站點數字編號（如札嘎其 110、南浦 111、奧西利亞 K122）。
  2. 🚪 **站內地下通道跟隨指標**：對照現場指示牌精確文字（如「Gukje Market / 國際市場」、「Jagalchi Market / 札嘎其市場」、「Gunam-ro / 龜南路文化廣場」）。
  3. 🪧 **韓國道路名銘牌解碼**：現場實證深藍底白字白邊金屬銘牌（大路 `DAERO`、路 `RO`、街 `GIL`），如 `[ JAGALCHI HAEAN-RO ]`、`[ GUKJESIJANG 1-GIL ]`，抬頭即知方向。
  4. 🏬 **官方門牌實址與店鋪名稱**：精確標註韓文與英文店名、樓層與攤位編號。
  5. 🧭 **肉眼轉彎地標識別**：包含出站看見之標誌建築、街角地標、轉彎參照物，杜絕原地繞圈。

- **四大指定願望深度專題解密**：
  - 🛏️ **國際市場「棉被一條街」採買攻略**：莫代爾（Modal）與極細纖維（Microfiber）材質解析、老字號名店指名（藝珠寢具 / 京信寢具）、現場抽真空（진공포장）SOP、裝箱托運技巧。買完直接步行 4 分鐘送回南浦飯店房間放好！
  - 🦀 **札嘎其魚市場推薦攤位與防坑手冊**：精選台灣遊客公認良心首選 **1 樓 100 號 / 101 號攤位**（老闆懂中文、當面扣籃重歸零、買帝王蟹大方加送鮮活貝類/烤魚、可刷卡）、183 號總角商會；2 樓代工料理費人頭費明細與必點「蟹膏炒飯 (게딱지볶음밥)」教學。
  - 👘 **甘川洞文化村韓服漫步**：村口名店「哲秀與英熙」精緻韓服＋燙金刺繡＋專人編髮飾品；小王子與沙漠狐狸雕像同框、粉彩山城階梯俯瞰平台經典機位。
  - 🏎️ **東釜山 Skyline Luge 斜坡滑車**：奧西利亞站接駁攻略、4 大競速賽道（Wind / Peak / Marine / Forest）特性解析、Visit Busan Pass 免費換票技巧。

- **首選名店 ✕ 超強應急備案機制**：
  每餐皆配置同區域頂尖備案（如南浦蔘雞湯 vs 元祖漢陽冷菜豬腳、西面味贊王 3.5cm 熟成厚切五花肉 vs 捕盜廳炭火排骨、海東龍宮海鮮大鐵盤炸醬麵 vs 機張市場雪蟹），遭遇排隊或公休可無縫切換。

- **在地美食八大名物全圖鑑**：
  活蒸帝王蟹、釜山豬肉湯飯、熟成厚切五花肉、元祖堅果黑糖餅、炭火起司烤扇貝、炭烤活盲鰻、古法高魚漿魚糕、砂鍋清燉河豚湯。

## 🗺️ 5 天 4 夜 行程動線矩陣（同天同軸線・零折返）

- **Day 1｜老城海味風華・國際市場棉被採購 ✕ 札嘎其帝王蟹饗宴**
  - 南浦洞商圈 ➔ 國際市場棉被一條街（挑選棉被＋抽真空放回飯店）➔ BIFF 廣場星光手印與元祖黑糖餅 ➔ 札嘎其市場大樓 1F 100號攤位大啖海鮮 ➔ 樂天百貨光復店頂樓港景夜色
- **Day 2｜傳統美學與絕壁海景・甘川洞韓服 ✕ 影島白淺灘 ✕ 西面頂級烤肉**
  - 甘川洞文化村（哲秀與英熙韓服換裝體驗 ➔ 小王子同框打卡）➔ 土城新昌清燉豬肉湯飯 ➔ 影島白淺灘文化村絕壁海景步道與海岸隧道 ➔ 松島海上水晶纜車 ➔ 西面「味贊王鹽烤肉」3.5cm 熟成厚切五花肉
- **Day 3｜東釜山極速狂飆・Skyline Luge 滑車 ✕ 海東龍宮 ✕ 廣安大橋夜色**
  - 東釜山 Skyline Luge 斜坡滑車（4 賽道重力俯衝）➔ 海東龍宮大鐵盤辣海鮮炸醬麵 ➔ 海東龍宮寺（建在海蝕崖邊的千年古剎）➔ 樂天 Outlet ➔ 廣安里海水浴場（廣安大橋落日與點燈夜景、週六無人機光雕秀、民樂水產大樓刺身野餐）
- **Day 4｜海岸浪漫鐵道・海雲台膠囊列車 ✕ 雙子燈塔 ✕ 五星汗蒸幕**
  - 海雲台藍線公園尾浦站搭乘「天空膠囊列車 (Sky Capsule)」海景慢遊 ➔ 青沙浦灌籃高手平交道與紅白燈塔 ➔ 青沙浦秀敏家炭烤扇貝大餐 ➔ Centum City 新世界百貨「Spa Land」天然溫泉汗蒸幕極致放鬆 ➔ 海雲台傳統市場（尚國家辣炒年糕 ＆ 炭烤盲鰻）
- **Day 5｜老釜山靈魂滋味・西面商圈採購與依依惜別**
  - 西面豬肉湯飯一條街（1946年創立松亭三代豬肉湯飯）➔ 田浦咖啡街紅磚工業風小巷漫步 ➔ 西面地下街美妝最後採買 ➔ 順暢抵達金海機場或 KTX 釜山站滿載返台
