## 🌟 核心特色與實地導航亮點

- **第一天晚抵直奔海雲台度假基地**：
  - 晚班機抵達金海機場後，免趕行程直奔海雲台入住（推薦龜南路核心飯店）。
  - 下樓即是龜南路文化廣場、海雲台海水浴場沙灘夜浪，以及營業至深夜/清晨的海雲台傳統市場。
  - 詳列深夜暖胃與宵夜指南（尚國家辣炒年糕、炭烤活盲鰻、24小時營業錦秀河豚湯、24小時密陽豬肉湯飯、營業至凌晨04:00的伍班長烤肉）。

- **全站一鍵直連 Google Maps 導航**：
  - 每一個景點、餐廳、備案、地鐵出口與轉彎地標皆嵌入一鍵開啟的 Google Maps 導航按鈕，隨開即走零迷航。

- **5 大維度實景路標無死角認路系統**：
  1. 🚇 **地鐵線路與車站官方色彩速查**：涵蓋 🟢 2號線（綠色）、🔴 1號線（橘紅）、🔵 東海線（深藍）、🟣 輕軌（紫色）官方配色代碼與站點數字編號（海雲台 203、奧西利亞 K122、札嘎其 110、南浦 111）。
  2. 🚪 **站內地下通道跟隨指標**：對照現場指示牌精確文字（如「Gunam-ro / 龜南路文化廣場」、「Gukje Market / 國際市場」、「Jagalchi Market / 札嘎其市場」）。
  3. 🪧 **韓國道路名銘牌解碼**：現場實證深藍底白字白邊金屬銘牌（大路 `DAERO`、路 `RO`、街 `GIL`），如 `[ GUNAM-RO ]`、`[ JAGALCHI HAEAN-RO ]`、`[ GUKJESIJANG 1-GIL ]`。
  4. 🏬 **官方門牌實址與店鋪名稱**：精確標註韓文與英文店名、樓層與攤位編號。
  5. 🧭 **肉眼轉彎地標識別**：包含出站看見之標誌建築、街角地標、轉彎參照物，杜絕原地繞圈。

- **四大指定願望深度專題解密**：
  - 🛏️ **國際市場「棉被一條街」採買攻略**：莫代爾（Modal）與極細纖維（Microfiber）材質解析、老字號名店指名（藝珠寢具 / 京信寢具）、現場抽真空（진공포장）SOP、裝箱托運技巧。買完直接步行 3 分鐘送回南浦飯店房間放好！
  - 🦀 **札嘎其魚市場推薦攤位與防坑手冊**：精選台灣遊客公認良心首選 **1 樓 100 號 / 101 號攤位**（老闆懂中文、當面扣籃重歸零、買帝王蟹大方加送鮮活貝類/烤魚、可刷卡）、183 號總角商會；2 樓代工料理費人頭費明細與必點「蟹膏炒飯 (게딱지볶음밥)」教學。
  - 👘 **甘川洞文化村韓服漫步**：村口名店「哲秀與英熙」精緻韓服＋燙金刺繡＋專人編髮飾品；小王子與沙漠狐狸雕像同框、粉彩山城階梯俯瞰平台經典機位。
  - 🏎️ **東釜山 Skyline Luge 斜坡滑車**：奧西利亞站接駁攻略、4 大競速賽道（Wind / Peak / Marine / Forest）特性解析、Visit Busan Pass 免費換票技巧。

- **每餐配置多重備用美食庫**：
  涵蓋活蒸帝王蟹、炭火起司烤扇貝、3.5cm 熟成厚切鹽烤肉、清燉與濃湯豬肉湯飯、海東龍宮大鐵盤辣炸醬麵、元祖堅果黑糖餅、古法高魚漿魚糕、砂鍋清燉河豚湯等 8 大名物圖鑑。
